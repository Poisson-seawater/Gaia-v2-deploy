# Utiliser Gaïa

Tu connais déjà la carte, les fractales et les couleurs. Cette page passe à l'usage réel : descendre dans le détail, comparer, et peser toi-même sur les données. On continue couche par couche.

## 1. Naviguer en profondeur

Tu sais déjà entrer dans un territoire. Ici tu vas jusqu'au bout : du monde jusqu'à ton quartier, en double-cliquant pour descendre et en suivant le fil d'Ariane pour remonter. Certains territoires sont à cheval sur plusieurs pays — ils comptent comme un seul.

→ [Naviguer en profondeur](#/hierarchie-fractale)

## 2. Comparer

Un même territoire se regarde sous plusieurs angles : 3 unités (Gaïa, énergie, carbone), 4 catégories de besoins, et les années disponibles dans les données. Les années système restent 1993, 2023 et 2050 ; les imports représentants peuvent ajouter d'autres années.

→ [Comparer](#/visualisations)

## 3. Contribuer

Avec un compte, tu ne fais plus que regarder. Tu ouvres un débat public sur une donnée. Si tu es nommé représentant d'une fractale, l'onglet Contribuer permet d'exporter un CSV complet, de le relire hors ligne, puis de réimporter les cellules modifiées pour tes fractales exactes. Chaque valeur modifiée porte sa propre source, URL et justification dans le fichier.

→ [Contribuer](#/contribution)

## 4. D'où viennent les chiffres

Chaque valeur affichée a une origine traçable : données générées par le code, CSV alimentation/achats figé au build, ou couche vivante Supabase qui superpose les corrections validées.

→ [Sources de données](#/sources-de-donnees)

## 5. Mode sombre et couleurs

L'interface bascule en mode clair ou sombre depuis le bouton d'en-tête, et garde ton choix d'une visite à l'autre. Les couleurs de seuil (bleu / rouge) restent identiques dans les deux modes.

→ [Charte graphique](#/charte-graphique)
